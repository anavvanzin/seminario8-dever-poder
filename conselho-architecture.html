Conselho de Contestação Algorítmica — Arquitetura

Sistema deliberativo multiagente para contestação de decisões algorítmicas • Google Cloud Run • Gemini AI

Stack Tecnológica

  • • Frontend: React 19 + Vite + TypeScript
  • • Backend: Express (server.ts) + Node.js
  • • IA: Gemini API (@google/genai) — gemini-3.5-flash
  • • Deploy: Google Cloud Run (us-west1)
  • • Fallback: Conselho.html estático (Plano B)

Fluxo Deliberativo (3 Fases)

  • • Fase 1: Cada persona emite parecer individual
  • • Fase 2: Avaliação cruzada entre personas
  • • Fase 3: Relator sintetiza parecer final
  • • 4 personas com perspectivas complementares
  • • Prompts diferenciados por persona e fase

Dados e Endpoints

  • • GET /api/cases — lista casos disponíveis
  • • POST /api/analyze-decision — executa análise
  • • GET /api/config-status — verifica disponibilidade
  • • 6 casos pré-carregados no servidor
  • • Fallback offline com respostas simuladas
